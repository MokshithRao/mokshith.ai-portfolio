LegalBERT — Contract Clause Classification

Fine-tuned LegalBERT for classifying contract clauses using the CUAD (Contract Understanding Atticus Dataset), a widely-used benchmark for legal NLP.

Technical Details:

  • Applied LoRA (Low-Rank Adaptation) via the PEFT library for parameter-efficient fine-tuning, significantly reducing training compute requirements.
  • Trained on multi-label classification of 41 clause types covering key legal concepts like termination, indemnification, and IP rights.
  • Evaluated model performance using precision, recall, and F1 metrics across clause categories.

HandDino — Chrome Dino with Hand Gestures

A computer vision project that lets you play the Chrome Dino game using hand gestures detected through your webcam.

How It Works:

  • Uses Google's MediaPipe framework for real-time hand landmark detection from webcam input.
  • Maps specific hand gestures (open/closed fist) to keyboard actions via PyAutoGUI to control the Dino's jump and duck movements.
  • Runs at real-time speeds with OpenCV for video processing and display.
